# Our Library

A small shared-library catalog built with Go and server-rendered HTML.

## Stack

- Go standard-library HTTP server
- PostgreSQL with [Goose](https://github.com/pressly/goose) migrations
- Type-safe queries generated by [sqlc](https://sqlc.dev/)
- HTML components generated by [Templ](https://templ.guide/)
- HTMX and Alpine.js
- Tailwind CSS and daisyUI
- Air for live reloads
- `just` for project commands

## Start the project

You need Go, Node.js, Docker, and [`just`](https://just.systems/).

```sh
cp .env.example .env
just setup
just db-up
just seed
just dev
```

Log in with the seeded local-development account, `dev@example.com`.

Open Air's live-reload proxy at <http://localhost:8090>. The application remains available directly at <http://localhost:8080>, with service health at <http://localhost:8080/healthz>.

The defaults use ports `8080` and `55432`. If either port is in use, update `HTTP_ADDRESS`, `POSTGRES_PORT`, and the port in `DATABASE_URL` in `.env`. When you change the application port, also update `proxy.app_port` in `.air.toml`.

Set `OPEN_LIBRARY_CONTACT` to an email address so Open Library can identify API traffic from your deployment.

## Common commands

```sh
just                 # list commands
just generate        # regenerate sqlc, Templ, CSS, and browser assets
just dev             # run with code generation and browser reloads
just run             # run without live reloads
just check           # generate, test, and vet
just build           # build bin/ourlibrary
just db-up            # start PostgreSQL
just db-down          # stop PostgreSQL
just migrate          # apply migrations
just seed             # migrate and add local development data
just user-add me@example.com
just new-migration add_members
```

During `just dev`, Air regenerates sqlc, Templ, and Tailwind output when their source files change. It then rebuilds the embedded assets and reloads pages opened through port `8090`.

## Project layout

```text
cmd/server/                     server application entry point
cmd/user/                       user administration CLI
internal/config/                environment configuration
internal/database/migrations/   Goose migrations
internal/database/seeds/        idempotent development seeds
internal/database/queries/      sqlc queries
internal/database/store/        generated sqlc package
internal/web/                    HTTP handlers and embedded assets
internal/web/templates/         Templ components
```
